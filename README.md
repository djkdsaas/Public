# Aureon Systems Concept Site

This repository contains a static concept page for Aureon Systems built with HTML and CSS.

## Preview the page locally

Because the project is a static site, there is no build step. You can open the design in a browser in either of the following ways:

1. **Open the file directly**
   - Double-click `index.html`, or
   - Drag `index.html` into an open browser window.

2. **Serve the folder locally**
   - From this directory run `python3 -m http.server 8000`.
   - Visit `http://localhost:8000/index.html` in your browser.

Using a local server avoids restrictions some browsers place on local file URLs and ensures fonts and assets load consistently.
